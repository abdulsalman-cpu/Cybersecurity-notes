# Muhammad Salman — Linux, Networking & Cybersecurity Labs

I am building hands-on IT skills through troubleshooting-focused labs. My goal is to understand **why systems fail, how to isolate the failing layer, how to fix it, and how to verify the result** rather than only memorize commands.

## Featured Troubleshooting Labs

### [Linux Service Troubleshooting](portfolio/linux-service-troubleshooting.md)
A repeatable workflow for connecting to a Linux server, checking a failed service, reading logs, correcting the problem, and verifying recovery.

### [Network Troubleshooting Map](portfolio/network-troubleshooting-map.md)
A layered diagnostic path: **interface/IP → routing → ARP/neighbor → DNS → TCP/port → application → verification**.

### [HTTPS / TLS Troubleshooting](portfolio/web-tls-troubleshooting.md)
Diagnosing HTTPS from port 443 and web-server configuration through TLS/SNI/certificates and the final HTTP response.

## How I Troubleshoot

My default approach is:

**Connect → observe symptoms → identify the layer → gather evidence → make the smallest appropriate fix → verify end to end**

This repository documents my continuing hands-on learning in Linux, networking, security, and automation.
