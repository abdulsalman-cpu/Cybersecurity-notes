## Linux

### Services and Logs

- `systemd` manages services and other system resources.
- Check a service with `systemctl status <service>`.
- Use `journalctl -u <service>` to review service-specific logs.
- Troubleshooting should move from the error message to evidence, then to the root cause.

### Permissions and Storage

- Linux access is controlled through the owner, group, and permission bits.
- Use `ls -l`, `chmod`, `chown`, and `chgrp` when checking access problems.
- LVM adds a flexible layer between physical storage and mounted filesystems.
- Before changing storage, verify the device, filesystem, mount point, and available space.

## Networking

### Core Concepts

- DNS translates names into IP addresses.
- Routing decides where packets should go next.
- TCP provides reliable, connection-oriented communication.
- A firewall permits or blocks traffic according to rules.

### Useful Checks

```bash
ip addr
ip route
ss -tulpn
ping <host>
dig <domain>
```

Read command output as evidence. For example, a missing route suggests a routing problem, while name resolution failure suggests DNS.

---

## Security

### Defense in Depth

Security is stronger when several controls work together:

- File permissions restrict local access.
- AppArmor limits what an application is allowed to do.
- `nftables` filters network traffic.
- Logging provides evidence for investigation.
- Updates reduce exposure to known vulnerabilities.

A firewall alone is not complete security. Host controls, application restrictions, monitoring, and careful access management support one another.

---

## Troubleshooting Workflow

1. Read the complete error message.
2. Categorize the problem: identity, permissions, service, DNS, routing, firewall, storage, or resources.
3. Choose a command that tests one suspicion.
4. Compare the output with the expected state.
5. Fix the root cause and verify the result.

## Key Takeaway

Linux, networking, and security troubleshooting are connected. Start with the symptom, identify the layer involved, gather evidence, and apply the smallest safe fix.
